# ChiaChat — WhatsApp-native AI language learning

ChiaChat teaches Spanish through WhatsApp. The student texts a number,
gets warm conversational replies from **Chia** (the AI teacher),
hears Chia speak via voice notes, and gets pronunciation feedback
on their own voice notes — all inside WhatsApp.

This Next.js app contains **everything that powers ChiaChat**:

- **Inbound message handling** (`/api/webhooks/whatsapp`) — verifies Meta's signature, routes by conversation state, dispatches to the right handler
- **Conversation handlers** (`lib/handlers/*`) — onboarding, free chat, structured lessons, audio TTS, voice-note → ElevenLabs agent handoff
- **Service clients** (`lib/messaging/*`) — Meta Graph API, OpenAI, ElevenLabs, audio caching
- **Stripe integration** (`/api/webhooks/stripe`) — plan upgrade, billing renewal
- **ElevenLabs voice loop bridge** (`/api/webhooks/elevenlabs`) — receives post-call data, updates memory + state
- **Cron jobs** (`/api/cron/*`) — hourly reminders, every-10-min memory updater
- **Admin dashboard** (`/admin/*`) — manage teachers, lessons, images, view users
- **Database schema + seed** (`supabase/*.sql`) — Chia and 5 starter Spanish lessons

See [ARCHITECTURE.md](./ARCHITECTURE.md) for the full module map and state machine.

## Environment variables

Copy `.env.local.example` to `.env.local` and fill in.

| Variable | Purpose |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Public client key (admin login) |
| `SUPABASE_SERVICE_ROLE_KEY` | **Secret** — used by every server-side write |
| `SUPABASE_STORAGE_BUCKET` | Defaults to `chiachat-media` |
| `STRIPE_SECRET_KEY` | Stripe API key |
| `STRIPE_WEBHOOK_SECRET` | Stripe → us signing secret |
| `STRIPE_PREMIUM_PAYMENT_LINK` | Pre-built Payment Link URL |
| `OPENAI_API_KEY` | GPT-4o-mini for chat + memory extraction |
| `ELEVENLABS_API_KEY` | TTS + Conversational Agent calls |
| `ELEVENLABS_CHIA_VOICE_ID` | Chia's voice in ElevenLabs |
| `ELEVENLABS_AGENT_ID` | Conversational Agent ID for voice-note loop |
| `ELEVENLABS_WEBHOOK_SECRET` | Bearer-token shared secret for `/api/webhooks/elevenlabs` |
| `META_WHATSAPP_ACCESS_TOKEN` | Long-lived system user token for Meta Cloud API |
| `META_WHATSAPP_PHONE_NUMBER_ID` | Numeric ID of the WhatsApp number (used in API URLs) |
| `META_WHATSAPP_BUSINESS_ACCOUNT_ID` | WABA ID that owns the number |
| `META_WHATSAPP_VERIFY_TOKEN` | Random string echoed back during webhook setup |
| `META_WHATSAPP_APP_SECRET` | Verifies inbound webhook HMAC signatures |
| `META_WHATSAPP_NUMBER` | The actual phone number in E.164 format |
| `CRON_SECRET` | Auto-generated by Vercel; auth on cron invocations |
| `ADMIN_EMAIL` | The single email permitted to log in to `/admin` |

## First-run checklist

### 1. Supabase project
1. Create a new project at [supabase.com](https://supabase.com)
2. SQL editor → run `supabase/schema.sql`
3. SQL editor → run `supabase/storage.sql`
4. SQL editor → run `supabase/seed.sql` (inserts Chia + 5 lessons)
5. Settings → API → copy URL, anon key, service role key into `.env.local`
6. Authentication → Users → add an admin user with the same email as `ADMIN_EMAIL`

### 2. Meta WhatsApp Cloud API
1. [developers.facebook.com](https://developers.facebook.com) → create App (type **Business**) → add the **WhatsApp** product
2. Setup wizard provisions a free test number; add your real production number to the WABA and verify via SMS (24–48h Meta approval)
3. Business Settings → System users → Add → role Admin → Generate **never-expires** token with permissions `whatsapp_business_messaging` + `whatsapp_business_management` → paste into `META_WHATSAPP_ACCESS_TOKEN`
4. Copy **Phone Number ID** + **WABA ID** into env. App Settings → Basic → copy **App secret** into `META_WHATSAPP_APP_SECRET`. Choose any random string for `META_WHATSAPP_VERIFY_TOKEN`
5. Once deployed: Meta App → WhatsApp → Configuration → Webhook → set URL to `https://YOUR-DOMAIN/api/webhooks/whatsapp`, paste the verify token, click Verify and save → subscribe to `messages` field
6. WhatsApp Manager → Message templates → create `chiachat_lesson_reminder`, body:
   ```
   Hola {{1}}! It's {{2}} 🌿 I haven't heard from you in a while — ready to practice your Spanish today?
   ```

### 3. ElevenLabs
1. Voice Library → pick a warm Spanish female voice → copy voice ID into `ELEVENLABS_CHIA_VOICE_ID` AND into Chia's row in the admin dashboard
2. Conversational AI → Agents → create agent named `Chia (ChiaChat)`. Paste the system prompt from `teachers.agent_voice_prompt` (visible after seed). Configure to respond to audio with audio.
3. Copy agent ID into `ELEVENLABS_AGENT_ID` and into Chia's row
4. Once deployed: agent → workspace post-call webhook → URL `https://YOUR-DOMAIN/api/webhooks/elevenlabs`, auth = Bearer `${ELEVENLABS_WEBHOOK_SECRET}`

### 4. Stripe
1. Create Product **ChiaChat Premium** with €25/month recurring price
2. Create a Payment Link for that price. Don't collect address/phone.
3. Once deployed: Stripe → Webhooks → add endpoint `https://YOUR-DOMAIN/api/webhooks/stripe`. Subscribe to: `checkout.session.completed`, `checkout.session.async_payment_succeeded`, `invoice.paid`, `customer.subscription.deleted`. Copy signing secret into `STRIPE_WEBHOOK_SECRET` (in Vercel env).

### 5. Local dev
```bash
npm install
npm run dev
```
Visit `http://localhost:3000/admin/login`.

### 6. Vercel deployment
1. Connect this repo to Vercel
2. Add every env var from the table above (paste from `.env.local`)
3. Deploy. Vercel auto-runs the cron jobs defined in `vercel.json` (hourly reminders + every-10-min memory updater)
4. Once deployed, complete the webhook URLs in steps 2.5, 3.4, 4.3 above pointing at your Vercel domain
